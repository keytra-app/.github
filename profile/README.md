## Keytra

Minimalist, self-hosted, open-source alternative to Crowdin.

- **[keytra](https://github.com/keytra-app/keytra)** — Self-hosted translation management platform (Next.js, Drizzle, PostgreSQL, Docker)
- **keytra-action** *(coming soon)* — Official GitHub Action for automated i18n push/pull workflows

Zero SMTP. JSON-first. Up and running in 60 seconds with `docker compose up`.
